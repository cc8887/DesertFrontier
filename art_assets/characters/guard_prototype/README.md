# 守卫低模与拉弓试作

- 建模规格：沿用 [项目正交参考图](../frontier_guard/README.md) 的五头身比例、空手 T-Pose、并脚、6.7774 项目单位设计高度。低模手工简化，不是照片扫描或像素级复刻。老年版本是深色短羊皮坎肩、银灰发须、深裤与绑带。
- 源文件：`young_guard.blend` 与 `elder_guard.blend`，各 25 骨（17 节身体骨、8 节飘带骨）。其中 `Ribbon.01–08` 为单根连续蒙皮布带，第一节挂头结，依次传递到尾端。静止 T-Pose 在 Blender 文件；战斗站姿和两个年龄的动作在 Godot 计算，不在 GLB 内烘焙。
- `build_guard.py` 用 Blender 4.3.2 重建源文件及运行时 GLB：从项目根运行 `blender -b --python art_assets/characters/guard_prototype/build_guard.py -- assets/guard`。
- `scripts/frontier_archer.gd`：两年龄共用接触、出箭和风骨骼逻辑；每个年龄独立定义动作时序、胸肩姿态、手位。场景世界风转为骨架空间，风速为零时飘带落下且不再摆动。不是布料碰撞解算。
- 本轮外部素材下载未通过；没有任何第三方弓射动画被导入、缓存或当成试作动作分发。动作由本项目程序关键姿态与两段 IK 生成。后续可重定向参考片段，不需要改武器或风骨骼接口。

## 回归

```sh
godot --headless --editor --import --quit
godot --headless --script tests/guard_archery_smoke.gd
godot --headless --script tests/defense_smoke.gd
godot --headless --script tests/winter_smoke.gd
godot --rendering-method gl_compatibility --script tests/guard_render_review.gd -- /absolute/capture-directory
```

防守冒烟使用实际游戏的按键/鼠标输入，核对预放箭无扣血、放箭一发一次、坡面遮挡和原有三轮流程。角色冒烟核对八节布带骨与风方向、零风稳定、固定放箭点、满弓两手接触和中途退出取消。录像是固定时间步的 Godot Compatibility 像素输出；不是对帧率或安卓性能的验收。

## NPR 材质与黑描边

- 本轮保持守卫身体几何、骨骼结构和拉弓/放箭不变。为原网格补了随蒙皮移动的绘画 UV 和连续法线；头绳仍是单根、四节，调整了条带宽度、长度及四节风向相位。
- `shaders/guard_painterly.gdshader`：Unlit 输出，场景主光方向做三段式软边明暗，宽笔触只扰动局部明暗与分段边缘。暖沙/冷雪共用一套着色器，保留米色坎肩、砖红布和银灰发须等识别色。沿用场景「笔触」「白日」「沙幕浓度」参数做联动。
- `scripts/guard_outline.gd` 与 `shaders/guard_outline.gdshader`：用同一个蒙皮及同一台游戏相机生成独立透明角色遮罩，向外扩约 1.45 px（以 720p 为基准）取纯黑轮廓。不沿着两块相接服装重复描线。描边在风雪、HUD 之下；退出防守不再更新额外视口。这个方案用于当前始终在前景的守卫，不是通用的场景遮挡描边。
- 一次额外角色遮罩绘制，边缘着色限制在局部矩形，不是全场景后处理。尚未在 Android 真机测量开销。
- `tests/guard_render_review.gd` 增加 `--edge-proof`：每个镜头记录同一姿态只关闭/开启描边的成对截图。

### 后脑飘带

两年龄都把布结放到后脑中线附近，重新定位单根四节蒙皮飘带。按头部姿态坐标约束条带向后，风向影响侧摆与翻卷；逆风不会将带子推到额头前。把第一节与头部固定，尾段带波动相位差，无风下垂。只改了布结、飘带和风驱动，NPR、描边、身体和射箭时序不变。

`godot --headless --script tests/guard_ribbon_rear_smoke.gd` 按实际的蒙皮权重检查两年龄、四个转向、多风向和整个拉弓循环；这是后脑平面约束，不是通用布料碰撞系统。

### 防守阵风

默认「风速」不变。防守中由慢起伏与短阵风共同推进风相位，用同一强度驱动贴近镜头的沙雪笔触与后脑飘带。飘带根部不离结，尾端有更大的滞后、升降和翻转；风速调到零时暖沙前景风层关闭，布带下垂。退出防守后不启用新的暖沙遮罩。未改角色 mesh、黑描边或射击时序。

`godot --headless --script tests/defense_wind_smoke.gd` 检查默认风的起伏、沙雪共用阵风相位、风速零值和退出恢复。固定两秒对照（同起始相位、默认风速、年轻待机）：第 4 节飘带骨的垂直摆幅从 0.352 到 1.014 项目单位，风相位位移从 0.580 到 1.519；这些不是现实风速。

### 双倍长度

两套飘带从原后脑结沿绑定位中心线延长至原来的 2 倍（2.617 → 5.234 项目单位）。各处横向宽度、头结位置、四节风骨与风向逻辑不变；黑色轮廓绘制范围随长飘带加宽，线宽不变。布料加了一层很薄的厚度，避免翻到侧面时出现断续。

### 八节飘带

保持双倍长度、宽度、后脑固定点与单根轮廓，沿同一中心线把 4 节拆为 8 节，网格沿长度由 16 段加密到 48 段。每个点最多由相邻 3 节共同驱动，权重连续过渡。风相位沿原带长归一化，不因增加骨数而加快波动。与 4 节版本同场景、同风相位的各两秒年轻/老年测试中，把中心线统一重采样成 48 段后，每帧最大局部折角的第 95 百分位从约 35.7° 降到 8.6°。这是本段动作与风势的对照，不是所有模式的上限。

### 分层 Aim At

防守时移动鼠标，脊柱、胸、头、双手与弓各自响应。先建立固定的骨盆与下肢站姿，再叠加 Aim At、年龄专属的拉弓曲线和双手接触。脚、膝、骨盆及人物的根节点不会被鼠标旋转。风动仍以头后约束和八节飘带为独立分支。

左键起弓，拉弓中照常移动鼠标；0.44 s 松弦时取此刻准星，旧的点击位置不锁定。保留现有的立即命中判定（相机射线、骑兵包络与沙丘遮挡）及从箭尾出发的视觉轨迹，不包含飞行时间或弹道物理。松弦后再移动鼠标不能改变已发出的这一箭。

运行 tests/guard_aim_at_smoke.gd，可用真实的输入事件分别核对两年龄的空处转靶、靶转空处、箭杆方向和下半身世界变换。用 Compatibility 有窗口运行 tests/guard_render_review.gd，传入输出目录以及 --video --aim-at，可录取拉弓时移动鼠标并实际命中骑兵的实战镜头。

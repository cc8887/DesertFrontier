# 大漠边疆 · 黄沙白日

把 Three.js 美术实验「黄沙白日」v11 移植到 Godot 4 的原生 3D 场景。不依赖浏览器、外部插件或网络。包含原版观景和一轮可重复游玩的前哨防守原型，不含建造系统、完整关卡或关卡编辑器。

## 运行

1. 使用标准版 Godot 4 导入根目录的 `project.godot`，按 **F5**。使用 Compatibility 渲染器和 GDScript，不需要 .NET。开发测试版本：Godot 4.7.2。
2. 底部拖动进度，或按 **1 / 2 / 3 / 4** 查看远脊扬蹄（1.68s）、下坡软影（7.4s）、谷地遮挡（12.5s）、越过近丘（16.6s）。
3. **Space** 播放/暂停、**R** 从头重播、**H** 隐藏界面、**F1** 重置。点「场景调色」调节沙幕、风速、日轮、沙粒、笔触、扬沙和光影；默认禁声，可点「开启声音」。

## 前哨防守

在观景模式点 **开始防守**（也可按 **Tab**）。画面保持固定，三骑依次在远脊亮相、扬蹄、迎面翻过近丘。等骑兵进入交战距离，鼠标指向露出的轮廓并点击左键；地形可以挡住出击。前三次来袭中，必须在前哨两点耐久耗尽前守完。**R** 重开，**Esc** 回到原来的观景位置。调色和声音沿用进入防守时的设置。

命中体积按马身和骑手当前骨架姿态构造，较真实轮廓留有少量容差；本版只有固定镜头和单一路线，不含武器成长或自由移动。

## 场景结构

- `scenes/desert.tscn`：主场景，固定透视镜头，竖向视角 43°。
- `scripts/desert_terrain.gd` 与沙丘、天空 shaders：三个真实 3D 沙丘网格、暖白日轮、视距衰减、随风运动的沙幕、静态印象派笔触和独立滚动的沙粒遮罩。
- `scripts/desert_route.gd`：保持网页原型的路线、远端扬蹄、转向和越脊节奏，坡面决定马身俯仰。
- `scripts/mounted_rider.gd`：原 GLB 的 Idle/Rear/Gallop 骨骼动画，以绝对时间采样；叠加程序化骑手与弱逆光。
- `scripts/desert_shadow.gd`：投影沿沙丘接收面铺开，远处掠射柔和过渡为贴坡短影。接触阴影独立于投影，地形和尘尾共用场景深度。
- `scripts/hoof_dust.gd`：落蹄小鼓尘和奔袭尾迹，风沙越浓、距离越远越弱，拖动时间轴可以重复看到同一帧。

Godot 和 WebGL 的色彩输出、纹理采样及抗锯齿不同，不承诺逐像素一致。

## 验证

```shell
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/smoke.gd
godot --headless --path . --script tests/route_shadow_regression.gd
godot --headless --path . --script tests/defense_smoke.gd
```

首次导入请先等 Godot 生成资源缓存。测试验证播放台、马匹骨架、下坡阴影、峡谷遮挡逻辑、动态风沙、回拖一致性，以及防守的命中、误射、输赢、重开与观景返回。无显示环境下的测试不代表 GPU 像素级验证。

马匹和声效见 [素材授权](assets/horse/CREDITS.md)。

## 风雪试景

按 **V**，或点观景／防守界面的「切换风雪」，往返「黄沙白日」与「风雪白日」。风雪和黄沙各自着色，共用原来的 3D 沙丘；积雪保留静止的大块笔触、灰蓝背光和近坡露出的薄沙，天空风雪持续横移。按 **2** 可对照远坡，按 **4** 则能看见近坡积雪与印迹。场景调色里的「风雪浓度」「风速」「飘雪强度」可分别调，原黄沙的马蹄扬尘在风雪模式不显示。

马蹄印跟着原始奔跑动画的落蹄相位，逐个压到真实坡面，旧痕被漂雪逐渐盖掉。在普通观景中可以拖动时间轴回看；前哨防守的新一骑重启时间轴并重置其尾迹。模型化的谷地没有连续雪地接收面，所以不在空中补印。

```shell
godot --headless --path . --script tests/winter_smoke.gd
```
